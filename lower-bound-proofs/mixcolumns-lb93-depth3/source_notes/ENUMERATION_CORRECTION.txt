Enumeration correction and independent audit, 2026-10-17

THE ERROR

A partition consists of sorted disjoint graph-code words. At a recursion
node with remaining support weight R and k remaining words, the next word
has weight at most floor(R/k). The bound need not hold for later words:
a small next word leaves a larger average for those that follow.

The old Python code intersected the persistent candidate set with this
weight bound, then passed that filtered set recursively. It could therefore
omit valid partitions. Both verify_pair25.py and verify_pair26.py used this
pattern. The prior saved PASS records did not establish exhaustiveness.

THE REPAIR

Use a separate variable eligible for the next-word choices, keeping the
original candidates for recursion:

  eligible = candidates & next_weight_mask & remaining_cycle_mask
  for j in eligible:
      recurse(candidates & compatibility[j], ...)

The compatibility mask already requires index greater than j, so retaining
candidates does not introduce duplicate orderings. Later words now remain
available even when heavier than the current next-word bound.
