# Review of the rank-three feedback repair

2026-11-13. Independent machine proof review of [RANK_THREE](../RANK_THREE.md). No circuit search or finite-family checks were run.

## Causal availability and gate budget

A consumer-bearing value is either a consumer input, the sum of two earlier consumer-bearing values, or the sum of one such value and an earlier source-side entry label. Thus its source part is in the span of the actual entry labels read along its ancestry, all earlier than the value. The source value of an exit is in the span of the labels read before it. This argument does not use any labels that are first generated by that exit or occur later.

In the source-only replay, every original source gate before the current one has already been supplied. Every source input and free base value is still available. An ordinary source gate can be copied or bypassed. At an exit, all earlier actual entry labels are physically available in the replay, even when their original gates were themselves exits. The exit value lies in their span, so the small-space lemma applies to the set of available nonzero values in \(D\). The set may include more values than those labels. This can only help and does not require any information from a later gate.

The small-space claim follows by taking an available basis. In rank at most two only the basis and possibly one pair sum are needed. In rank three a fourth available value is either a basis-pair sum or the three-term sum, and then every missing value is a one-XOR sum. If exactly three independent values are present, only their total sum might cost two gates. Using two gates creates both that missing output and a new pair sum. The available \(D\)-values thereafter contain a rank-three set with at least four members, so no later exit can incur the same extra cost. Retaining added values ensures this monotonicity. The theorem can be stated with zero available as usual in the free-side model. If zero must be supplied physically, the first original zero source-side gate can supply it once, using at most its one-gate budget; zero is never the exceptional three-term sum.

The replay uses at most one gate per original source-side gate except at the single possible exceptional exit. Dimension at most two avoids the exception. Source values outside \(D\) need not disappear: ordinary source gates still compute them. They may also furnish a cheaper one-XOR realization of an exit than the lemma guarantees. The upper bound does not assume otherwise.

## Application to the ten-gate consumer

Granting every zero-consumer operand free makes the ten consumer-bearing gates a local four-triple circuit, even if some of those operands were produced by exits in the original graph. The quotient-deletion bound forces each actual label into the required diagonal space \(D\), since any nonzero quotient direction would make the local cost at least eleven. Their span contains, and hence equals, \(D\). A source-only replay must supply all four first-side rows and these labels, including three independent nonzero diagonals. The exact augmented lower bound gives \(G_0+1\ge12\).

At total 21, a cost-preserving replay would have at most eleven source gates and is impossible. Thus an exceptional exit must occur. At that step its source value cannot have a one-XOR decomposition using any earlier physically available source values, including values outside \(D\) or new values created by the replay. Otherwise that replacement would avoid the only possible overhead. No saving at another step can cancel the overhead for a replay of size twelve, again by the augmented minimum. These are necessary conditions on a 21-gate candidate and do not establish one. A consumer with more than ten gates need not have all labels in \(D\).

The sharp general fragment uses three independent source values and one consumer coordinate. Its exit gives the sum of all three source values in one original source-side gate, while a source-only circuit from those base values requires two. The witness concerns the general causal model, not the joint MixColumns map.
