The note now explicitly bypasses returns whose values were already physically available and defines each useful return as a first supply of a nonzero source value. This clarification matters: a redundant reader need not have its partner in the selected tree, and a useful partner cannot be `u`, since that pair merely returns the already supplied entry label `h`. Distinct useful return values give distinct partner vertices, so the later `d-r` count is justified.

For a common entry tree, the identity `t_x=h+value(u)+value(x)` is valid because every vertex has the same ordinary consumer mask. Along either orientation of an edge, the two translated values differ by its actual source label. Starting from the already supplied `t_u=h` therefore permits traversal from `u` to any return partner using only source XORs.

The change of root creates no chronological assumption. Every edge on the path between `u` and `w_j` belongs to one of their original chronological root paths. Its source label was consequently read by the production time of one endpoint, and both endpoints precede the exit being replaced. At that exit time, all path labels are available. If a label originally depended on an earlier feedback return, that earlier source value has already been preserved by the same chronological induction. A label on this path cannot depend on the current exit because it precedes that exit in the original acyclic circuit.

The credit argument remains valid while other feedback is present. A synthetic translate already available needs no gate. If its first original source producer is later, its early computation uses only currently available path labels, and that particular later producer can be bypassed when reached. Distinct advanced values charge distinct producers. The current exit may itself supply the credit; later exits, including other returns using the removed entry, may also be credited. This does not grant future operands early: it advances a value through a different causal expression and removes its later original computation. Every other original source value and consumer gate remains available at its original position by induction.

All synthetic gates have zero consumer part. Every direct reader of `v` was a source exit and is now either bypassed or supplied by a translated path. Thus deleting `v` leaves at most `K-1` consumer-bearing gates. Only distinct translated nonzero values outside the original physical source set lack a credit, giving source count at most `G_0+B`. The assertion is correctly a partial feedback removal theorem, with no claim that unrelated feedback disappears.

The vertex count is exact for the minimal connecting tree: `d` edges give `d+1` vertices, of which the root and `r` distinct useful partners are already credited. Hence `B<=d-r`. In a star, its centre is the only possible unrequested connecting vertex. With at least two useful partners, a tree with at most three edges likewise gives `B<=1`. These are sufficient bounds; additional original physical translated values may reduce `B` further.

For the twelve-consumer application, a cost-preserving removal would create a joint circuit below 22 with at most eleven consumer gates, which the established bounds exclude. Therefore a surviving common-component tail requires `B>=2` and at least four entry edges.
