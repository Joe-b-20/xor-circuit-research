# Independent review: entry-return rigidity

2026-11-13. I checked [ENTRY_RETURN_RIGIDITY.md](../ENTRY_RETURN_RIGIDITY.md) against its stated model and the cited all-nonclean interface theorem. I found no material gap in the collision-defect inequality, the causal and unique-pair consequences, or the affine-plane return restriction. This is a hand review; no circuit search or enumeration was used.

For the collision count, the source projection fixes every target, keeps the nonzero consumer mask of each counted gate, and makes all nodes in each `C`-coset equal. In topological order, retain the earliest representative and redirect later uses to it. Distinct ordinary consumer inputs have different consumer masks, so every redundant representative is a paid gate. Counting physical nodes with multiplicity is valid even for already equal values; free copy wires are not counted as extra nodes. Further collisions under the selected projection can only delete more gates. Source-side values read by the consumer are supplied free in this local comparison, so consumer gates used solely as exit ancestors need not be trimmed: they remain in the physical count and can contribute to the collision defect.

For the causal refinement, the two operands of a nonzero exit have equal consumer masks and source difference `f` in `C`, furnishing a collision before every selected later entry. Each chosen entry creates a later physical gate node in the same `C`-coset as its earlier consumer-bearing operand. Thus each adds one to the defect, even when several additions land in an already occupied class; the earlier exit collision cannot be double-counted as a later node.

For the unique-pair consequence, first normalize the full circuit by replacing any duplicate gate value with its earliest available identical value. This is a chronological bypass and cannot introduce a dependency on a later gate; it remains valid when an affected gate feeds only an exit. Then translation by nonzero `f` pairs distinct consumer values, and two distinct such pairs contribute at least two to the `<f>` collision defect. An actual entry already supplies one pair, so the `K <= L_D+1` allowance excludes any second pair or second occurrence. An exit using the sole pair occurs after both operands, while `f` was already present before the entry produced its later operand; consequently such an exit can be bypassed. The note correctly limits this conclusion to a direct returned label, not feedback through other source operations.

For the five-entry application, the cited theorem is stated for the target-trimmed consumer. If an eleven-gate consumer has all entries outside `D`, target trimming retains at most eleven consumer gates, and the theorem forces exactly eleven; hence no additional counted gate exists solely outside that trimmed subcircuit. The four dependent labels are four distinct points of one affine plane `q+W` in the nonclean coset, while the fifth `h` lies outside their linear span. Since the entry span is `D+<h>` and `dim D=3`, the complementary affine plane is `h+W`. Causal span containment puts every exit in that entry span; the five labels themselves are excluded as nonredundant returns by the unique-pair result. The only remaining nonclean return values are the three `h+w` with nonzero `w` in `W`. This conclusion also permits arbitrary clean exits and does not charge virtual differences as gates.
