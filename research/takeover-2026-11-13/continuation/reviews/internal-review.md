# Independent review: internal visible events

Hand review of `../INTERNAL.md`, including the exact window criterion, the component projection bound, its symbolic examples, the MixColumns construction, and the conditional numerical profile. No SAT, exhaustive enumeration, exact-gate search, or computer-driven case elimination was used. This is not formal verification.

## Verdict

The stated two-window criterion is necessary and sufficient for algebraic feasibility of two local operand masks with the specified output value and whole-block cancelled set. The component projection theorem and its maximal linear-annihilator assertion are correct under their stated “locality plus fixed outside mask” scope. The displayed reduced no-hidden MixColumns circuit is valid in the stated model, and the conditional `G >= 84-2m` profile follows from the 84-form repair bound and the given support and independence assumptions. None of these assertions establishes a new unrestricted MixColumns lower bound.

## Window criterion and component rank

For an event with surviving support `R` and cancelled block set `C`, both operands contain all blocks of `C`, while every block of `R` appears in at least one operand. Thus two windows containing their respective supports must each contain `C` and jointly cover `R`. Conversely, partition `R` among two such windows and give each operand the corresponding nonzero components of the desired output plus exactly the same prescribed nonzero component on each block of `C`. Their XOR is the target; blocks in `C` and only those blocks cancel completely. The construction proves feasibility of values and does not assert that those values already exist or are cheap to compute.

For selected values supported within `S`, nonlocal operand vertices joined by an event edge have equal projections outside `S`. Equality propagates within each physical component, and this common outside mask is nonzero because `S` is contained in a window. Every local partner has this same outside mask and therefore must live in a window containing its support. Such a partner is zero on `D_i`, the part of `S` outside the union of all such windows. Projecting each assigned event to `D_i` leaves the sum of one or two projected nonlocal vertex values. The rank is therefore at most the number of vertices in that component; different component vertex sets are disjoint. The parity lift and the full-rank-plus-one estimate when there are no local partners also follow from the respective odd/even incidence vectors.

The maximality claim about linear annihilators is justified in precisely its stated scope. If a coordinate unit belongs to `S\\D_i`, then some window contains that coordinate's block together with the whole outside support, so `z_i+e` is a geometrically admissible local value with outside mask `z_i` and restriction `e`. Hence the possible restrictions span the entire coordinate subspace on `S\\D_i`; all vanish on `D_i`. Any linear map annihilating all possible restrictions must annihilate this whole subspace and thus factor through projection onto `D_i`. This does not describe additional constraints from the actual available nodes, costs, or the complete cancellation pattern.

The three proper-support symbolic examples have the claimed visibility and rank behavior. In particular, the multi-block signature example has only the `a_i` nonlocal hidden gates, and the pairwise test misses the event's `A,L` blocks even though the exact window intersection separates `A`. The augmented-parity example has ordinary projection rank zero but lifted rank one, attained by its sole hidden gate. The independent proper-support events with zero hidden gates are also valid: their two operands are designated outputs and each event reaches its designated descendant without a further event.

## Actual MixColumns no-hidden example

Writing the sheet-2 own inputs as `x_i` and predecessor inputs as `z_i`, the construction has `u=z_0+z_1`, `a=u+x_1`, `b=u+x_2`, and event `f=a+b=x_1+x_2`. Direct symbolic substitution verifies the four displayed sheet-2 rows: their own parts are the correct triple sums `E_c` and their predecessor parts are the correct pairs `s_c`. The only event among those displayed gates is `f`; both `a` and `b` also reach designated sheet-2 outputs without going through it.

For all remaining sheets, each added gate lies on an event-free coordinate-input chain to a designated output. Equal-value reuse preserves operand values, and pruning removes dead work. The only way to introduce an event into such a continuation would be to reuse the event node `f` as a chain prefix. Only sheets 2 and 3 contain block 2, and for sheet 3 only the row with predecessor pair `x_1+x_2` could otherwise produce this pure prefix. Starting that row's chain on block 3 avoids it. Hence the resulting reduced live circuit has exactly one event, namely the proper-support internal visible gate `f`, and has `H=0`. No small gate count is claimed.

## Conditional MixColumns profile

For `S={2,3}`, the only MixColumns output window containing both blocks 1 and 7 is `W_1={0,1,7}`, disjoint from `S`. If a selected event's two operands have common outside-`S` support containing 1 and 7, at least one operand is nonlocal: if both were local, both containing windows would have to be `W_1` and could not cover the event's nonempty support in `S`. In each resulting component, any window containing the whole outside mask is either `W_1` or absent. Thus `D_i=S`, and the component rank bound gives `H` at least the rank of all selected values. For `m` independent values, `H>=m`.

When these events are the complete visible set of a reduced circuit, none contains block 0, so no sheet-1 borrower correction occurs in the 84 form. None contains both 2 and 7; hence each `kappa` is at most 3. Substituting `H>=m` into `G>=84+H-sum(kappa)` gives `G>=84-2m`, or the stated sharper expression `84+m-sum(kappa)` when individual penalties are known. Other visible events would contribute their own penalties, so the complete-visible-set hypothesis cannot be omitted.
