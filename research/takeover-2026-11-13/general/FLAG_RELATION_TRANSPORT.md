# One gate transports one relation unit along a flag

2026-11-14. Structural arguments for unrestricted binary XOR continuations
from an actual supplied dictionary. Sharing, cancellation, dependent supplied
values, arbitrary intermediate values, and zero or repeated gate values are
allowed. An [independent machine review](reviews/flag-relation-transport-review.md)
is saved. No formal verification, human certification, or literature novelty
is claimed.

The [subspace preparation theorem](SUBSPACE_PREPARATION.md) measures the growth
of accessible relations inside one subspace. Adding those growth counts across
subspaces is generally invalid: one gate can improve many of them at once.
For nested subspaces there is an exact replacement. One gate transports one
rank unit between two layers of the flag, regardless of how many intermediate
subspaces benefit. A flag chosen from the actual output order also gives zero
credit to every required-output first-production gate.

## 1. A flag of accessible relation spaces

Let S be a finite actual dictionary of nonzero supplied values, V=span(S), and
fix a flag

    0=W_0 <= W_1 <= ... <= W_k=V.

Repeated subspaces may be omitted without changing any bound below. For a
current actual dictionary D, define

    R_i(D) = span((D intersect W_i) union
                 {u+v : u,v in D, u+v in W_i}).           (1)

This is the relation space from the subspace theorem: if both parents of a
pair are in W_i their sum is already generated by D intersect W_i; otherwise
they have the same nonzero W_i-quotient color. Equivalently, with D^+=D union
{0},

    R_i(D)=span((D^+ + D^+) intersect W_i).

The adjoined zero is notation for supplied singletons in this expression,
not a free physical zero operand. These spaces are nested:

    0=R_0(D) <= R_1(D) <= ... <= R_k(D)=V.

Write r_i=dim R_i(D), and define the current and desired layer dimensions

    c_i=r_i-r_(i-1),             d_i=dim W_i-dim W_(i-1).

Both sum to dim V. A completed computation containing spanning values for
each W_i has R_i=W_i and consequently c_i=d_i for every layer.

## 2. The exact interval law

**Flag transport theorem.** Adding one actual gate output changes the rank
profile (r_i) either nowhere or by adding one precisely on an interval

    a <= i < b.                                           (2)

In the latter case it changes the layer profile by

    c_a <- c_a+1,              c_b <- c_b-1,               (3)

and leaves every other c_i unchanged. Moreover, if the gate output v belongs
to W_j, then b<=j. Thus one gate transports one rank unit from a later layer
to an earlier layer. It is not charged once for every cut in (2).

**Proof.** If v is zero or already supplied, nothing changes. Otherwise let
a be the first index for which v+u belongs to W_a for some u in D^+. Such an
index exists because W_k=V. Fix this u and put w=v+u. For every i>=a, each
other new pair difference v+u' in W_i satisfies

    (v+u')+w=u+u' in R_i(D).

Therefore R_i(D union {v})=R_i(D)+span{w}. Before a there are no new pair
differences. Since the old R_i are nested, w is absent from them until its
first membership index b and then remains present. If b=a there is no rank
change; otherwise exactly the ranks in (2) increase. Membership eventually
holds because R_k(D)=V. Taking successive differences proves (3).

Finally suppose v=p+q is the gate's actual expression and v in W_j. Its old
parents show v in R_j(D): either both are in W_j or they have the same
nonzero quotient color. We also have a<=j by choosing u=0 when defining a.
The fixed u=v+w belongs to D^+ intersect W_j, so w=v+u belongs to R_j(D).
Thus b<=j. QED.

The interval assertion itself holds for adjoining any vector in V. The final
endpoint restriction uses the actual binary gate and its available parents.

## 3. A potential that does not count an interval repeatedly

Put

    q_i=dim W_i-r_i,                 q_0=q_k=0,
    Phi(D)=sum_(i=1)^k max(0,q_i-q_(i-1)).                (4)

Equivalently,

    Phi(D)=sum_i max(0,d_i-c_i)
          =(1/2)*sum_i |d_i-c_i|.                       (5)

This counts the rank units missing from their final layers, rather than the
number of cuts crossed by those units. A gate transfers at most one unit by
(3), so Phi changes by -1, 0, or +1. If the outputs span every W_i, its final
value is zero and hence

    G >= Phi(S).                                         (6)

More exactly, let N_down,N_up,N_flat count gates that decrease, increase,
or preserve Phi. Then

    N_down-N_up=Phi(S),
    G=Phi(S)+2*N_up+N_flat.                              (7)

These are identities for the actual circuit. A gate that preserves Phi can
still transport a relation unit; it just fails to reduce the current mismatch
of layer dimensions.

**Exact meaning of the rank relaxation.** If one retains only nonnegative
layer dimensions and the prefix conditions q_i>=0, Phi is exactly the minimum
number of abstract leftward unit transports needed to reach c=d. For a
nonzero q, let [a,b) be its first positive run. Layer a is deficient because
q_(a-1)=0<q_a; layer b has a surplus because q_(b-1)>q_b=0. Moving one unit
from b to a subtracts one from q on that run, preserves nonnegativity, and
reduces Phi by exactly one. Repeating reaches zero in Phi moves, matching
the lower bound.

This relaxation discards actual dictionary values, available parents, and
the physical endpoint restrictions from the gate theorem. Thus bare layer
data alone cannot require more than Phi unconstrained moves. Further circuit
cost must use information beyond that rank-transport relaxation.

**Why the ordinary sum is invalid.** Supply independent coordinates
a,b,c,x_1,...,x_(h-1), and let

    W_i=span(a+b+c,x_1,...,x_(i-1)),       1<=i<=h.

Append V to this flag. Every initial q_i for 1<=i<=h equals one. Yet the
single gate a+b increases every one of these relation ranks: its difference
from the old value c is a+b+c. Summing the h individual growth requirements
overcounts one actual gate by an arbitrary factor. Formula (4) gives one.

## 4. An actual output order assigns no credit to output gates

Select distinct required nonzero targets T={t_1,...,t_M}, all absent from S.
Other required values may be present too. In an arbitrary competing circuit,
order these selected targets by their actual first appearance and use the
prefix flag

    W_j=span(t_1,...,t_j),        0<=j<=M,
    W_(M+1)=V.                                          (8)

Targets need not be independent. Repeated prefix spaces can be retained or
omitted. Every W_j is spanned by available targets at completion.

**Monotone layer activation.** Every strict target-prefix step has dimension
jump one. For such a step, c_i>0 holds exactly when the current dictionary
has a singleton or pair-sum generator in W_i minus W_(i-1). If every short
generator in W_i instead belongs to W_(i-1), each already belongs to
R_(i-1), and R_i=R_(i-1). Conversely a generator outside W_(i-1) cannot
belong to R_(i-1), so it makes c_i positive.

Once such a witness is available, it remains available under dictionary
growth. Thus a layer with c_i>0 never becomes empty again. Since d_i=1 at
these steps, its contribution max(0,d_i-c_i) to Phi is one precisely when
the layer is empty. An appended final jump to V never contributes a
deficiency: c_final-d_final=q_previous>=0. Therefore Phi counts initially
empty target layers that remain unactivated. It NEVER increases under
dictionary growth along these prefix flags. An actual gate activates at
most one empty layer by the interval theorem, so it decreases Phi by zero
or one.

This monotonicity holds for every target-prefix order; chronology is needed
separately for the next assertion. The general-flag account (7) remains
valid, but its N_up term vanishes for the flags considered here.

**Zero output credit.** Every selected target's first-production gate leaves
ALL the flag relation spaces unchanged. At the first production of t_j, each
earlier prefix W_i, i<j, is already spanned by available targets and therefore
has R_i=W_i. Every later prefix contains t_j, and a gate inside a subspace
cannot increase that subspace's relation space. This also covers targets
dependent on earlier ones.

Call all other gates auxiliary for this count. They may compute useful
intermediates, other required outputs, or repetitions; they are still charged
as real gates. Exactly M gates are selected first productions. Writing
Z=N_flat-M>=0 and using N_up=0, (7) gives the exact account

    G = M + Phi(S) + Z.                                  (9)

Exactly Phi(S) auxiliary gates activate previously empty target layers;
Z counts all remaining auxiliary gates. For a bound
depending only on the supplied dictionary and selected targets, minimize
over their possible orders sigma:

    G >= M + min_sigma Phi(S; prefix flag of sigma).     (10)

No enumeration of orders is prescribed. The statement quantifies over the
order of every unrestricted competing circuit; structural arguments can
bound the minimum for a particular target family.

The order qualification matters. For targets t=a+b+c and u=a+b from coordinate
inputs, the flag beginning with t has Phi=1, while the flag beginning with u
has Phi=0. The two-gate circuit u=a+b, t=u+c has no auxiliary gates. An
arbitrarily selected flag cannot claim the zero output credit of (8).

## 5. A cost before the first flag movement

The initial flag profile also has a distance cost. If Phi(S)>0, some proper
cut is initially unsaturated. Define

    Delta_* = min_(i:q_i>0) min_(w in W_i minus R_i(S)) ell_S(w),
                                                               (11)

where ell_S is actual dictionary word length. Each inner minimum is at least
three by the subspace preparation theorem. For the actual-order flag (8),

    G >= M + Phi(S) + Delta_*-3.                         (12)

**Proof.** Consider the first gate that changes ANY R_i and choose a cut W_i
it changes. Before that gate the cut still has its initial relation space.
No selected target outside W_i has previously appeared: such an appearance
would come after all the prefix targets spanning W_i, forcing R_i=W_i and
making the proposed increase impossible. Thus all outside-W_i gates up to
this event are auxiliary.

The first-collision proof in the subspace preparation theorem gives at least
Delta_i-2 outside-W_i gates through the event, where
Delta_i=min_(w in W_i minus R_i(S)) ell_S(w). All but the event itself precede
every flag-rank change, so they are counted in Z. Consequently

    Z >= Delta_i-3 >= Delta_*-3.

Substitution in (9) proves (12). QED.

If Phi=0, use correction zero rather than defining Delta_*. Minimizing the
right-hand correction Phi+Delta_*-3 over output orders gives another
target-only bound. The distance and Phi must come from the SAME order.

For a single parity of D>=3 independent coordinates this gives the exact
D-1 gate cost: M=Phi=1 and Delta_*=D. For the actual prepared dictionary in
[the common-offset family](COMMON_OFFSET_PREPARATION.md), every nonempty
target prefix has relation space equal to its even target combinations.
Thus q_i=1 throughout the target prefixes, Phi=1, Delta_*=2r+1, and (12)
recovers the exact remaining cost M+2r-1. All retained prefix intermediates
are included in that statement; their cost remains separately charged.

## 6. A sharp unrestricted family of full-rank maps

On four independent coordinates a,b,c,d require

    t_1=a+b+c,        t_2=a+b+d,
    t_3=a+b+c+d,      t_4=b+c+d.                         (13)

These four targets form a basis: d=t_1+t_3, a=t_3+t_4,
b=t_2+a+d, and c=t_1+a+b. A five-gate construction is

    h=a+b,
    t_1=h+c,         t_2=h+d,
    t_3=t_1+d,       t_4=t_3+a.                         (14)

For EVERY ordering of these targets, the initial deficiency profile along
their prefix flag is

    (q_0,q_1,q_2,q_3,q_4)=(0,1,1,0,0).                 (15)

The first target has weight at least three, so its line has no initial
relation. In any two-target span, the target difference has weight one or
two, while the two targets themselves have weight at least three. This gives
exactly one initial relation dimension. Every coordinate-input hyperplane
has its full initial relation space: its quotient has only one possible
nonzero color, and the coordinate formula dim R=n-t gives dim R=n-1.
The full space is also saturated. These facts prove (15), so Phi=1 for every
order. Bound (10) gives five gates, attained by (14).

Now take B disjoint four-coordinate blocks with these targets on each block.
An arbitrary global output prefix spans the direct sum of its within-block
prefix spaces. Its INITIAL relation space is the direct sum of their initial
relation spaces. Indeed, a cross-block sum of two coordinate inputs belongs
to this prefix space only if each coordinate already belongs to its own
block's prefix space; then the relation is already generated blockwise.

Every output ordering, including arbitrary interleavings, therefore has one
positive deficiency increment per block, by (15). Thus Phi=B and M=4B, giving

    exact unrestricted complexity = 5B.                 (16)

Separate copies of (14) attain the bound. The lower-bound proof permits
competing circuits to mix blocks and cancel later; no circuit direct-sum
assumption is made. This is a sharpness family for the general account, not
a restriction on its competing circuits.

## 7. Accessible closure still has a physical computation cost

Use independent coordinates a,x_1,...,x_(m+1) and require the odd targets

    t_i=a+x_i+x_(i+1),                    1<=i<=m.        (17)

For their natural prefix order,

    R_i(S)=span{x_j+x_(j+2) : 1<=j<i},
    dim R_i(S)=i-1,                       q_i=1.

Indeed, a sum of path-edge targets has x-support equal to the boundary of its
selected edges, and includes a exactly for an odd number of edges. There are
no weight-one vectors. A weight-two vector comes from an even-length subpath,
so its endpoints have the same index parity. The displayed two-step pairs
generate all these vectors and have rank i-1. Thus Phi=1 and Delta_*=3.
The full-target certificate (12), minimized over orders, is exactly m+1:
every first target has weight three, forcing Phi>=1 and Delta_*=3 in any
order, while the natural order attains Phi=1.

The exact unrestricted complexity is m+ceil(m/2), by the known common-anchor
result of Boyar, Matthews, and Peralta, recalled with a proof in
[the common-anchor graph note](COMMON_ANCHOR_GRAPH.md). For attainment, choose
a minimum vertex cover of the path, compute a+x_j for each of its ceil(m/2)
vertices, and obtain each target by adding the other endpoint. Their exact
result permits arbitrary sharing and cancellation. Here this known family
is used to identify the limit of the new flag certificate.

Every target here has weight three. Thus the gap between m+1 and the actual
cost cannot be blamed on overlooking one long target. The flag account misses
physical preparation: every natural prefix cut has only one missing relation
direction, while computing accessible even generators still costs real gates.

Selecting fewer targets cannot strengthen this certificate. Select p>=1
edges of the original path, forming c nonempty path components. The same
boundary argument gives initial relation rank p-c in their full target span:
a component with l edges contributes l-1 independent same-index-parity pairs,
and the components use disjoint endpoint coordinates. No weight-two relation
can join different components, because a nonempty edge subset in each such
component has at least two boundary vertices. Consequently the last selected
prefix has q=c, forcing Phi>=c in every order. Grouping the selected components
and proceeding along each component achieves Phi=c: its q increases by one
when a component starts and stays fixed while that component is extended.

The first selected target has weight three, so Delta_*=3 in every order.
Thus the minimized certificate for that subset is exactly p+c. There are
at least c-1 omitted edges separating its components, so

    p+c <= m+1.

The full target set attains m+1. Therefore even maximizing (12) over ALL
selected target subsets leaves this bound at m+1, compared with the exact
m+ceil(m/2). One cannot then add the omitted outputs' gate count for free:
their gates may advance the selected flag and are already charged among
its auxiliary gates. This limitation concerns the stated chronological flag
certificates, not every possible use of target-subspace information.

Retaining a and x_1 as identity outputs gives a square all-odd invertible map.
Recover x_(i+1)=t_i+a+x_i successively, so the example does not rely on a
singular target map.

## 8. A quantitative ceiling on the bare complete-flag certificate

For coordinate inputs in dimension n and an ordered basis of n targets,
the prefix flag is complete: dim W_i=i. Let t_i count the distinct nonzero
quotient colors of the input coordinates modulo W_i. Then

    q_i=i-n+t_i,
    q_i-q_(i-1)=1-(t_(i-1)-t_i).                         (18)

Colors never increase in number. Hence Phi is exactly the number of steps
where t_i=t_(i-1). A quotient by one new direction has fibers of size two.
Counting the zero color too gives

    t_i+1 >= ceil((t_(i-1)+1)/2),
    t_i >= floor(t_(i-1)/2).                             (19)

Starting at t_0=n and ending at t_n=0 therefore requires at least
ceil(log_2(n+1)) strict-drop steps. Consequently

    Phi <= n-ceil(log_2(n+1)).                           (20)

This ceiling is attained by some ordered flags. Let k=ceil(log_2(n+1)) and
choose a rank-k matrix with n distinct nonzero binary columns, for example
the binary labels 1,...,n. Its kernel has dimension n-k and no nonzero vector
of weight one or two. A flag starting with a basis of this kernel has n-k
plateau steps. Its remaining k steps must all be strict drops by (19), so
Phi=n-k. This does not assert attainment after minimizing over all orders
of a fixed target basis.

In particular, for n=M=32 the bare certificate M+Phi in (10) is at most 58.
The distance correction in (12) is separate and is not bounded by (20).
The flag law solves the multiple-credit problem for nested relation ranks,
but its bare potential cannot prove the published MixColumns lower bound
75, much less improve it. No new numerical MixColumns bound is claimed.

The [specified checker](checks/check_flag_and_anchor.py) and
[saved results](checks/flag-anchor-result.json) verify actual gate-by-gate
interval changes, persistent layer occupation, zero first-output credit and
the exact auxiliary account. Three interleaved blocks give 15=12+3+0; a
seven-edge path gives 11=7+1+3; the cancelling triangle gives 5=3+1+1.
A fixed wrong-order example has Phi=1 versus actual-order Phi=0, and one
specified gate advances six nested cuts with only one unit of credit.
These are direct construction and linear-algebra checks, not searches or
independent computational proofs of the symbolic lower bounds.
