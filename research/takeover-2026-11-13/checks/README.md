# Direct verification

Run from the repository root with Python 3 and the standard library:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 research/takeover-2026-11-13/checks/projection_check.py
PYTHONDONTWRITEBYTECODE=1 python3 research/takeover-2026-11-13/checks/hidden_check.py
```

`projection-results.json` records 12 specified cases. The code propagates only requests
generated by each fixed circuit, constructs the repair, and verifies all linear masks,
output values, gate counts, and absence of whole-block cancellations. It also verifies
the five-output counterexample and its alternative optimal event-free circuit. The
MixColumns matrix from AES multiplication agrees with the repository matrix.

The three fixtures are the exact gate lists previously cited as `circuits_2.txt:783`,
`circuits_3.txt:1451`, and `circuits_3.txt:3001`, using the historical loader's nonempty-line
numbering. They were copied from the existing external corpus so the checks are reproducible
from this branch alone. The witness builder is imported only to evaluate its fixed
block-order construction; its script entry point is not run.

`hidden-results.json` records the four-vertex-star instance of the symbolic sharp family:
seven independent selected events and exactly four hidden operands attain `7=2*4-1`.

No test performs SAT, exhaustive enumeration, least-gate search, circuit optimization,
or computer-driven case elimination. These checks support the hand arguments and catch
implementation mistakes; they do not establish universal theorems or certify optimality
beyond the explicit output-count proofs in the notes.
