## Single-sheet algebra and the three-gate case

With `E=(I+J)e` and `s=(I+P)e`, the own-to-neighbour map is `(I+P)(I+J)=I+P=R` because `(I+P)J=0`. The kernels have the stated dimensions: `ker R` is the all-ones line, `R^2=I+P^2` has dimension-two kernel, `R^3=J`, and `R^4=0`.

For a maximal-window sheet, a nonlocal operand has a nonzero block outside the window and maximality gives an incompatible block `d` in the window. Every local completion vanishes on `d`, so its differences lie in the kernel of that block projection. On the own block the kernel is zero; on any neighbour block it is the line generated by the sum `t_j` of all four rows. A proper subset of the row basis does not contain `t_j`, proving the singleton classification. For the full row space, an affine intersection with that line has zero, one, or two points. If two occur, one has nonzero own-block component; a window containing it also contains the other because the two differ only on that own block.

For four selected output events with three nonlocal operand gates, the componentwise separated-rank bound forces all four events into one component: any component assigned fewer than four independent rows needs at least as many vertices as assigned rows. Full-row rank then requires a one-dimensional completion-difference space. Independence of the full event values forbids cycles in the nonlocal-operand graph, so three connected vertices give two edges and the remaining two events have local partners. On an incompatible neighbour block the four row masks have rank three and the unique all-four relation, so the three vertex projections are independent and the two local-partner events attach to opposite endpoints of the path. Summing the four physical gate equations then gives `local_partner_1 + local_partner_2 = t_j`. The partners have the same nonzero outside-window projection; at least one has nonzero own-block projection, so it is a gate local to a different window containing the own block. This need not be a hidden gate.

## Two-sheet formulas and profile

For distinct `j,k`, the stated own-block equations are triangular because their windows have no reciprocal own-block incidence; the map from `(x,y)` to the two own components is invertible, so the combined span has dimension eight. An affine completion in `a+K` has no content outside window `U` exactly when the displayed equations `b_d=a_d` hold there.

If `U` omits both own blocks, the triangular homogeneous equations force `x=y=0`. If it contains both, independent omitted-neighbour incidence vectors give independent rank-three equations after applying `R`, yielding kernel dimension `8-3rho`. If it omits only `j`, substitution gives `x=epsilon R y` and the remaining constraints `alpha R y + epsilon beta R^2 y=0`. Whenever `alpha=1`, this is either `R y=0` or `R(I+R)y=RPy=0`; both have kernel `ker R`, which also satisfies the other possible constraint. Without such a constraint, an `epsilon R^2 y=0` condition gives dimension two, and its absence gives dimension four. The interchanged case is identical. These statements concern a single eligible window's homogeneous directions; several windows can contribute independent representative differences as the note correctly warns.

For the specified block-4-cancelling outputs of sheets 2 and 3, every component's common outside mask contains block 4. Any local partner therefore vanishes on blocks 1 and 2, neither of which co-occurs with 4 in a window. The projection of the full eight-row span to those blocks has kernel `Rx=0, x+Ry=0`, equivalently `x=Ry, R^2y=0`, of dimension two; its rank is six. Componentwise ranks sum to at least the rank of the total span, giving six distinct nonlocal gates. When one component's outside support is exactly block 4, a local completion lies in `W_4` or `W_5`; any `W_5` completion has no block-5 content and also lies in `W_4`. The direction space is thus the single two-dimensional `K intersect V_W4` plane. Finally, if precisely these eight events are visible, the displayed 84-form accounting gives `84+6-20+4=74`; it is a profile statement, not an unrestricted improvement.
