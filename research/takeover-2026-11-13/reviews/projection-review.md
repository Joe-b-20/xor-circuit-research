# Review of global repair by projected uses

2026-11-13. Independent machine proof review. No circuit searches or finite-family checks were run.

## Request propagation and gate cost

The request construction and repair proof hold for circuits with nonzero designated outputs. A request \((v,S)\) keeps a nonempty subset \(S\subseteq B(v)\) of the support of the value at \(v\). Linearity allows its XOR operands to be projected on the same \(S\), including blocks on which an operand is zero. The requests \(S\cap B(a)\) and \(S\cap B(b)\) are precisely the nonzero operand projections. At least one is nonzero, because the requested result is nonzero. If both are present, agreement on any nonzero block would force that block out of \(B(v)\), contrary to its membership in \(S\). Thus the new gate is event-free. Otherwise the request uses an existing wire. Topological order applies because every request reads earlier physical nodes. The construction handles nested cancellations and repeated original operands. For example a repeated operand gives an original zero gate, which receives no requests.

The count \(K=\sum_v q(v)=G-Z+X\) follows by counting productive requests per physical gate. With event-free lower bound \(B\), \(G\ge B+Z-X\). Taking \(B=84\) for the natural MixColumns blocks is justified by the block-monotone proof and event-free support growth. The required \(X-Z\ge9\) at \(G=75\) is arithmetic from the inequality.

## Identifying requested masks by value

The refinement by projected masks is valid. Let \(P\) be the set of distinct nonzero requested masks other than the original coordinate inputs. Start with all coordinate inputs and process requests in physical topological order. At a first appearance of a mask in \(P\), the request cannot be nonproductive. A nonproductive request has one nonzero operand projection equal to the result, and that operand request would already have appeared at an earlier node. Therefore the first appearance can use one new gate, with its two operand masks already available. Redirecting either operand to any earlier wire with the same mask preserves the event-free property, which depends only on the two masks. All later appearances use the first wire. This realizes exactly \(P\) as the set of gate masks before optional dead-gate pruning, so \(|P|\le\sum_v q(v)\) and an event-free realization costs at most \(|P|\).

For a reduced input circuit let \(V\) be its set of non-input gate masks, \(D=|V\setminus P|\), and \(A=|P\setminus V|\). Then \(|V|=G\) and \(|P|=G-D+A\), giving \(G\ge B+D-A\). The count \(|P|\) also applies to unreduced circuits. For them the exact set identity uses \(|V|\), which may be smaller than \(G\).

## Sharpness and the failure of a converse

For the prefix construction with singleton blocks, write \(t_i=y_1+\cdots+y_i\) and \(p_i=x+t_i\), \(1\le i\le n\). The circuit builds the \(p_i\) by a chain and builds \(t_n=p_n+x\) in one gate. Each \(p_i\) receives both its full support and the \(t_i\) support. The latter is nonproductive only at \(p_1\), and the request for \(t_n\) at its original output is nonproductive. Therefore \(Z=1\), \(X=n-1\), and \(K=2n-1\). The requested set of non-input masks is \(p_1,\ldots,p_n,t_2,\ldots,t_n\), of size \(2n-1\). The event-free optimum is \(2n-1\): the \(t_n\) cone uses at least \(n-1\) gates and avoids \(x\), while each of the \(n\) distinct \(p_i\) output gates contains \(x\). A chain for the \(t_i\) followed by adding \(x\) attains the lower bound. The unrestricted \(n+1\) is also optimal by the distinct non-input outputs. Both repair bounds are sharp here.

An extension gives an explicit failure of the implication from positive \(X-Z\) to savings. For \(n\ge3\), also designate all \(t_2,\ldots,t_{n-1}\) as outputs. In the original circuit build them by a separate \(y\)-prefix chain, while still using \(t_n=p_n+x\). The original circuit and an event-free circuit each have exactly \(2n-1\) gates, equal to the number of distinct non-input outputs. The original circuit is reduced and live, yet still has \(X-Z=n-2\). The repair by mask equality handles the example exactly, with \(P=V\) and \(A=D=0\).

Positive \(A-D\) also need not mean savings, as shown by a different reduced live example. Use singleton inputs \(a,b,c,d\) and require the five distinct outputs \(a+b\), \(a+b+c\), \(a+b+c+d\), \(b+c+d\), and \(c+d\). An unrestricted five-gate circuit builds the first three in order, then \(b+c+d=(a+b+c+d)+a\), then \(c+d=(b+c+d)+b\). The event-free optimum is also five. Compute \(a+b\), \(c+d\), \(a+b+c=(a+b)+c\), \(b+c+d=b+(c+d)\), and \(a+b+c+d=(a+b)+(c+d)\). The requested mask \(b+c\) arises by projecting \(a+b+c\) for the \(b+c+d\) output. All five original gates are output gates, so \(D=0\) and \(A\ge1\). Thus the projected set can exceed the event-free optimum even at an optimal reduced live circuit.
